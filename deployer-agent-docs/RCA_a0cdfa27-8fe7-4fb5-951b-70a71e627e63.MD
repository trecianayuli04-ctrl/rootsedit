# RCA — kas-selisih-check (run a0cdfa27-8fe7-4fb5-951b-70a71e627e63)

## Symptom
Initial deploy failed at **build_image**, Cloud Build step #39 `[frontend-build 13/14]`:
```
error @react-native/dev-middleware@0.86.3: The engine "node" is incompatible with this module.
Expected version "^20.19.4 || ^22.13.0 || ^24.3.0 || >= 25.0.0". Got "20.19.2"
error Found incompatible module.
```
Failed on the frontend `yarn install` (all 3 retries), command:
`yarn install --prefer-offline --check-files --network-timeout 100000 && yarn build`.

## Root cause — template / toolchain mismatch
The frontend is an **Expo React Native** app (`expo-router`, `react-native@0.86.3`,
`expo@57.0.25`; `app.json` web.bundler=metro, output=single), but the deployment template is
`fastapi_react_mongo_shadcn_base_image` — the **FARM / shadcn React-web** template and its base
image. Two compounding blockers result:

1. **Node engine gate.** `react-native@0.86.3` pulls transitive `@react-native/dev-middleware@0.86.3`
   which declares `engines.node >= 20.19.4`. The platform frontend base image
   (`fastapi_react_mongo_shadcn_base_image_cloud_arm:release-08102026-1`, per `.emergent/emergent.yml`)
   ships node **20.19.2**. yarn v1 enforces `engines` by default → `yarn install` hard-fails.
   The node version comes from the platform-injected base image and cannot be changed via manifest.

2. **No build command.** `frontend/package.json` has **no `build` script** (scripts: start, android,
   ios, web, lint, reset-project). Both `Dockerfile.cloudbuild` (frontend-build stage) and
   `build-frontend-artifacts.sh` run `yarn build`, which would fail even past the engine gate. The
   correct Expo web build is `expo export --platform web` (emits a static `dist/`, already handled by
   the downstream copy/upload logic).

## Fix applied (staged, not yet run)
Authored a complete manifest override set (config.yaml + Dockerfile + Dockerfile.cloudbuild +
entrypoint.sh + nginx.conf + build-frontend-artifacts.sh). Targeted changes in the three build files:
- `yarn install` → add `--ignore-engines` (bypass the conservative engine declaration; the Expo/metro
  web toolchain runs fine on node 20.19.x — the 20.19.2 vs 20.19.4 gap is a patch-level declaration).
- `yarn build` → `yarn expo export --platform web` (produces `dist/`; downstream already copies
  build/ or dist/).
entrypoint.sh / nginx.conf passed back unchanged. Staged on pending run
`5077783d-c2b5-402f-a41d-a6a40b0c4077`.
